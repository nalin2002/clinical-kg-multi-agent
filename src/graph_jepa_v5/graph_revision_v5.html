Graph-JEPA v5

Confidence-Aware Candidate Ranking

Version 5 extends the staged, schema-aware v4 pipeline with a training objective that directly ranks hidden true edges above plausible candidate distractors. It can also use LLM confidence and known clinical artifacts as tri-state supervision instead of treating every observed edge as truth.

For implementation details, see Graph-JEPA v5 Internal Workflow.

Why v5 exists

v4 improved graph revision by separating masked pretraining from joint fine-tuning and by converting schema-invalid observed edges into negatives. Candidate generation, however, is a ranking problem: among several schema-valid edges that could be added, the real patient edge should outrank nearby alternatives.

v5 adds that ranking signal. It also preserves edge-level confidence metadata from source KGs so low-confidence LLM edges, uncertain edges, and trusted edges can play different training roles.

Core workflow

1. Load
Convert patient KGs to tensors while preserving confidence, LLM origin, and clinical-artifact flags for every retained edge.
2. Sanitize
Remove schema-invalid edges from message passing. During pretraining, low-confidence LLM edges are removed as well.
3. Pretrain
Learn masked patch representations and save graph_jepa_v5_pretrain.pt.
4. Revise
Fine-tune relation-balanced BCE on trusted positives and several negative sources.
5. Rank
Hide trusted edges and rank each one above schema-valid relation, source, and target distractors from the same patient graph.
6. Score
Reuse v4 schema-guarded inference for keep, review, prune, and candidate-addition decisions.

Confidence supervision

With --llm-tri-state-supervision, LLM edges are divided using fallback thresholds of 0.3 and 0.8. Relation-specific thresholds in the checkpoint override those fallbacks.

Observed edge Training role Message passing
Non-LLM or high-confidence LLM edge Trusted positive Included when schema-valid.
Low-confidence LLM edge Weak negative Excluded; BCE weight defaults to 0.2.
Middle-confidence LLM edge Ignored Excluded from fine-tuning message passing and labels.
Known clinical artifact Weak negative Excluded when --clinical-artifact-filters is enabled.

Fine-tuning objective

loss = jepa_weight * patch_jepa_loss
     + revision_weight * relation_balanced_revision_bce
     + ranking_weight * candidate_ranking_cross_entropy

Patch JEPA

Predicts hidden patch representations from visible graph context using the online and EMA target branches inherited from v4.

Revision BCE

Separates trusted observed edges from absent schema-valid triples, schema-invalid edges, reversed invalid edges, and optional weak negatives.

Candidate ranking

Places one hidden true edge ahead of up to eight hard distractors by default, using temperature-scaled cross entropy.

Ranking distractors

Distractor family Example transformation What it teaches
Alternate relation Keep source and target, replace the relation with another schema-valid relation. Choose the correct clinical semantics.
Alternate target Keep source and relation, select another type-compatible target in the same graph. Link the correct patient entity.
Alternate source Keep relation and target, select another compatible source in the same graph. Distinguish nearby plausible causes or actors.

Fawkes MIMIC commands

1. Masked pretraining

PYTHONPATH=src python -m graph_jepa_v5.pretrain \
  --data mimic-subkgs \
  --mimic-subkg-path outputs/fawkes_mimic_graphs_4k_5k/sub_kgs/train \
  --out ckpts/fawkes_global_v5 \
  --encoder mock \
  --gnn-backend pyg \
  --epochs 40

2. Candidate-ranking fine-tuning

PYTHONPATH=src python -m graph_jepa_v5.finetune \
  --data mimic-subkgs \
  --mimic-subkg-path outputs/fawkes_mimic_graphs_4k_5k/sub_kgs/train \
  --checkpoint ckpts/fawkes_global_v5/graph_jepa_v5_pretrain.pt \
  --out ckpts/fawkes_global_v5 \
  --epochs 40 \
  --llm-tri-state-supervision \
  --clinical-artifact-filters \
  --ranking-neg-per-pos 8

3. Score the test split

PYTHONPATH=src python -m graph_jepa_v5.score \
  --input outputs/fawkes_mimic_graphs_4k_5k/sub_kgs/test \
  --checkpoint ckpts/fawkes_global_v5/graph_jepa_v5.pt \
  --output outputs/fawkes_mimic_graphs_4k_5k/sub_kgs_revised_v5 \
  --add-candidates \
  --max-candidates 50

Improvements over v4

Area v4 v5
Candidate learning Binary edge revision only. Additional listwise ranking against hard candidate distractors.
Observed-edge trust Schema-valid observed edges are positives. Optional high, middle, and low confidence training roles.
Clinical artifacts No source-specific artifact mask. Optional weak negatives for administration carriers and cancelled microbiology nodes.
Pretraining graph Schema-sanitized. Schema-sanitized and stripped of low-confidence LLM edges.
Monitoring JEPA, revision, and schema metrics. Adds ranking counts, confidence exclusions, artifact exclusions, and dropped-edge metrics.

Current limits

  • Confidence is supervision metadata, not calibrated clinical truth.
  • Artifact filters are narrow lexical rules for known data artifacts.
  • Candidate ranking only compares entities already present in the graph.
  • Scoring behavior is inherited from v4; confidence affects training, not the inference formula.
  • Added candidates remain unverified and do not gain transcript evidence automatically.
